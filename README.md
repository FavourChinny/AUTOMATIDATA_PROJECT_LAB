# AUTOMATIDATA_PROJECT_LAB
This project uses Python, Pandas, Matplotlib and Seaborn to analyze transportation data.


 ## PROJECT OVERVIEW 
   Automatidata Project Lab is a data analytics project focused on exploring and understanding transportation trip data. The project          involves data cleaning, exploratory data analysis (EDA), statistical analysis, correlation analysis and data visualization using Python.

 ## PROJECT OBJECTIVES

   - Clean and prepare the transportation datasets for analysis.
   - Perform exploratory data analysis to understand the structure and distribution of data.
   - Examine the relationship between fare amount, distance and trip duration.
   - Investigate passenger count patterns.
   - Use statistical correlation analysis to identify strong and weak relationship.
   - Create meaningful visualizations to communicate analytical findings.
   - Develop data-driven insights that can support transportation and operational decision-making.
